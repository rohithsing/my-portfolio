Welcome to the source code of my personal portfolio. Designed with precision, aesthetics, and performance in mind, this project serves as a central hub for my skills, experience, and the software I've built.

## ✨ Features

- **Sleek Aesthetic UI**: Designed with modern web trends in mind—glassmorphism, subtle gradients, and floating micro-animations.
- **Dark & Light Mode**: Seamless theme switching that remembers your preference.
- **Dynamic Projects Showcase**: Filterable gallery of my latest Front-end, Full-stack, and Software Engineering work.
- **Custom Chat Widget**: An interactive, custom-built chat assistant right on the homepage.
- **Fully Responsive**: Carefully crafted to look perfect on desktop, tablet, and mobile devices.
- **High Performance**: Lightning-fast load times powered by an optimized build setup.

## 🛠️ Tech Stack

This project is built using modern, industry-standard web technologies:

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Hosting**: [GitHub Pages](https://pages.github.com/)

## 🚀 Getting Started

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rohithsing/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:3000` to view the site.
